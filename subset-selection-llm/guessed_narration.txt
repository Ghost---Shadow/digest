SLIDE 9 — Why does ICL work?
--------------------------------------------------------------------------------
ON SLIDE: Three images — (1) decomposition of demonstrations into

experiments limited to classification/multi-choice.

NARRATION:

SLIDE 16 — MIPS (3/3)
--------------------------------------------------------------------------------
ON SLIDE: Bi-encoder equation — p_eta(z|x) proportional to exp(d(z)^T q(x)),
d = BERT_d(z), q = BERT_q(x). Document = z, Query = x.

NARRATION:

query and do a fast search."

SLIDE 38 — Active Example Selection
--------------------------------------------------------------------------------
ON SLIDE: Reward function r(s,a) with annotations. Q-learning formula
Q*(s,a). Two small figures.

NARRATION:
"Now it is reinforcement learning. The state is the current set of
demonstrations, the action is which shot to add next, and the reward
is the marginal improvement. The Q-learning formulation captures
something greedy methods miss — a shot that looks weak on its own
might set up the context perfectly for the next one."

[--> "There is a cleaner way to handle quality and diversity together."]


================================================================================
SLIDE 39 — CEIL (1/2)
--------------------------------------------------------------------------------
ON SLIDE: DPP formula P(S) with bullet explanations of each variable.

NARRATION:
"Determinantal Point Processes. The first term is quality — how
similar each selected item is to the query. The second term is the
log-determinant, which encodes diversity. If you pick two similar items
the determinant shrinks, so the model naturally pushes for spread. No
lambda to tune — quality and diversity in one unified formula."


================================================================================
SLIDE 40 — CEIL (2/2)
--------------------------------------------------------------------------------
ON SLIDE: Four bullets — embed, find n similar, check LLM likelihood,
split into S+/S-, train with contrastive loss. Loss formula shown.

NARRATION:
"Training is end-to-end. For each query, find the n most similar
documents, check their likelihood with the LLM, split into top half
and bottom half. The contrastive loss trains the embedding space so
that the DPP kernel learns what helpful-and-diverse looks like."

[--> "All these methods rely on the LLM for scoring. Can we do it
without the LLM entirely?"]

SLIDE 41 — Selective Annotation
--------------------------------------------------------------------------------
ON SLIDE: Graph/network figure. Text about voting with exponential decay.

NARRATION:
"Graph-based method, completely different philosophy. Build a graph
over the documents. Each document casts votes for its neighbors, but
the more votes it casts, the weaker each vote gets — exponential decay.
This prevents any single hub document from dominating and naturally
spreads the selection across different regions."

[--> "Can we combine this graph intuition with the DPP idea?"]

SLIDE 42 — Two-Stage DPP
--------------------------------------------------------------------------------
ON SLIDE: Pipeline figure — D -> SBERT -> L_S -> DPP -> D_sem. Then
influence scores -> Q -> I -> L_I -> DPP -> D_dem. Multiple formulas.

NARRATION:
"Two stages, two DPPs. First DPP uses semantic similarity to get a
diverse candidate set. Then compute influence scores for each
candidate — how much does it help? — build a new kernel from those
scores, and run a second DPP. First stage gives you coverage, second
stage gives you quality."


================================================================================
SLIDE 43 — IDEAL
--------------------------------------------------------------------------------
ON SLIDE: Five bullets — all-to-all similarity, seed set, top-K expansion,
acceptance probability inversely proportional to similarity.

NARRATION:
"Start with a seed set, find the most similar items, but add them
back with probability inversely proportional to how similar they are
to what you already have. So if something is very close to an existing
selection it is unlikely to be added. The expansion naturally spreads
out rather than collapsing into one cluster."

[--> "And one last idea that keeps showing up in recent work."]


================================================================================
SLIDE 44 — Selection Via Proxy
--------------------------------------------------------------------------------
ON SLIDE: Four bullets — least confidence, train proxy, rank by proxy
scores (forgetting events, uncertainty), select subset.

NARRATION:
"Instead of scoring with the expensive target model, train a small
cheap proxy model and use it to rank. Score by things like forgetting
events or uncertainty, and select the top subset. Surprisingly
effective, and this proxy idea has become very common in recent data
selection work for both pre-training and fine-tuning."
